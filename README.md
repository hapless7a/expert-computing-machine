# Simple Calculator

A lightweight calculator built with HTML, CSS, and vanilla JavaScript. No build tools or dependencies are required.

## Run it

Open `index.html` in a web browser.

## Features

- Addition, subtraction, multiplication, and division
- Decimal numbers, sign toggle, and backspace
- Keyboard support: number keys, `+`, `-`, `*`, `/`, `.`, `Enter` (calculate), `Backspace`, and `Escape` (clear)
- Responsive layout with accessible button labels
- Displays an error for division by zero
